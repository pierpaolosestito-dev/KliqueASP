Stima di memoria del Worker clingo

Questa sonda inizializza il Worker di produzione, esegue una query ASP minima e chiede al browser una misura dopo il solve.

La misura API è specifica del browser e riguarda l'app web. Sono riportate separatamente le voci attribuite al realm DedicatedWorker; il risultato non è RSS e le attribuzioni possono essere aggregate.
